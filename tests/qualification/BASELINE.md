## Evidence and gates

- Complete instrumented Release CTest: Linux 21/21 groups; Windows 23/23.
- Twelve-round local campaigns with TLS: 888 actions under Linux TSan and
  696 under Windows ASan, all passing after the documented fixture correction.
- Winsock fault cases additionally pass twelve repetitions under Windows UBSan.
- The platform baselines gate module percentages and measured header loss;
  unexpected new unmapped headers also fail. Floors and the explicit rounding
  policy are reviewed data, never automatically regenerated by CI.
- Profile inventories associate all 79 observed profiles on each OS with
  their own executable target. Zero-profile probes receive no test credit.
- The first Windows measurement exposed untested Winsock startup failure:
  network condition coverage was 1/2. Three injected failure codes plus exact
  cleanup/recovery tests now cover 2/2; this module has 7/7 executable lines.
- The expanded campaign found a timing-dependent publication fixture.
  Controlled tests preserve immediate and timer early-publication requirements,
  including two consecutive publication failures and stale-wake cancellation.
  The corrected Windows processing group passed 200 repetitions under ASan
  and 200 under UBSan.

Current source reports and gates are defined in [README.md](README.md),
[linux.json](baselines/linux.json) and [windows.json](baselines/windows.json).
The original failed campaign is retained in local audit evidence; successful
reruns follow a fixture correction, not an automatic retry policy.

Header inventories were updated on 2026-11-10 after splitting declarations
and moving the transports. `byte_storage_options.h` and `cache_entry.h` contain
data declarations; `tcp.h` now only selects a platform. The Linux TCP wrapper
inherits its constructor, while the Windows wrapper defines one. The Windows
constructor is now tracked in `tcp_windows.h`, and `tls_factory.h` is tracked
on both platforms. Platform alternatives remain unmapped. Coverage floors and
the original measured totals above are unchanged.

Local evidence: out/reliability/2026-11-04, including source hashes, original
per-object LLVM exports, HTML, the failed run, fresh campaigns and validation.
The first remote CI run is still pending. No Git operation or publication was
performed. Production headers and the normal Release policy remain unchanged.

## Next coverage-driven work

cleanup/scheduling and TLS error paths. Classify unreachable/configuration-only
paths explicitly before adding any exclusion. Further stateful native/TLS and
filesystem/cache fuzzing and broad allocation-failure sweeps remain tracked
in the [security audit](../security-audit.md).
